================================================================================
SCHOOLIQ - GOOGLE GEMINI & ENTERPRISE GCP VERTEX AI CONFIGURATION GUIDE
================================================================================

This document outlines the setup, environment configuration, and multi-server 
deployment instructions for Google Gemini AI and Enterprise GCP Vertex AI in SchoolIQ.

--------------------------------------------------------------------------------
1. CONFIGURATION MODES IN BACKEND (.env)
--------------------------------------------------------------------------------

MODE A: STANDARD GEMINI API KEY (Single Developer / Basic Setup)
-----------------------------------------------------------------
GEMINI_API_KEY=AIzaSy...your_gemini_api_key
GEMINI_MODEL=gemini-2.5-flash-lite
GEMINI_EMBEDDING_MODEL=text-embedding-004


MODE B: ENTERPRISE GCP VERTEX AI (Recommended for SchoolIQ Production)
-----------------------------------------------------------------------
USE_VERTEX_AI=true
GCP_PROJECT=your_gcp_project_id
GCP_LOCATION=us-central1
GOOGLE_APPLICATION_CREDENTIALS=/path/to/gcp-service-account.json
GEMINI_MODEL=gemini-2.5-flash-lite
GEMINI_EMBEDDING_MODEL=text-embedding-004

--------------------------------------------------------------------------------
2. MULTI-SERVER / MULTI-TENANT VERTEX AI SERVICE ACCOUNT SETUP
--------------------------------------------------------------------------------

When scaling SchoolIQ across multiple VPS servers or cloud environments:

STEP 1: Create a Service Account in Google Cloud Console
--------------------------------------------------------
1. Go to GCP Console -> IAM & Admin -> Service Accounts.
2. Click "Create Service Account".
3. Service Account Name: schooliq-vertex-ai-sa
4. Grant Role: "Vertex AI User" (roles/aiplatform.user).
5. Click "Done".

STEP 2: Generate & Download JSON Key File
-----------------------------------------
1. Click the created Service Account -> Keys tab.
2. Click "Add Key" -> "Create new key".
3. Select "JSON" and click "Create".
4. Save the downloaded file as "gcp-service-account.json".

STEP 3: Deploy to Backend Servers
---------------------------------
1. Place "gcp-service-account.json" inside your backend directory (or /etc/schooliq/keys/).
2. Add the path to backend/.env:
   GOOGLE_APPLICATION_CREDENTIALS=./gcp-service-account.json

--------------------------------------------------------------------------------
3. ARCHITECTURE CODE REFERENCE
--------------------------------------------------------------------------------
Singleton AI Factory: backend/src/modules/rag/shared/aiClient.js
- Automatically initializes GoogleGenAI in Vertex AI mode when USE_VERTEX_AI=true or GCP_PROJECT is set.
- Respects GOOGLE_APPLICATION_CREDENTIALS for seamless auth across any cloud provider.
- Throws an immediate startup error if required variables are missing.
